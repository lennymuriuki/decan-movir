# Decan Movie — Desktop & Mobile User Guide

## Navigation
Decan Movie Desktop organizes everything into 10 dedicated sections on the left navigation rail:
- **Home:** Featured hero spotlight carousel, Continue Watching (with resume progress bars), Trending Now, Popular Dramas, Recently Added, Popular Movies, Popular Series, Popular Anime, Recommended For You, and curated rails.
- **Movies / Series / Anime / Dramas:** Genre/region filters, sorting (`Featured`, `Top Ranked`, `Top IMDb`, `Newest`, or Anime `Top Ranked` / `Most Popular` / `Airing Now`), and Load More pagination.
- **Search (`Ctrl+K`):** Instant search across catalog providers, autocomplete suggestions, trending keywords, and category filter tabs (`All`, `Movies`, `Series`, `Anime`, `Dramas`).
- **Watchlist:** Track saved titles by `Watchlist`, `Watching`, `Watched`, and `Favorites` with 1–5 star personal ratings and notes.
- **Downloads:** Live download queue (pause, resume, cancel, progress bar) and automatic folder library organizer (`Movies/<Title>`, `Series/<Title>/Season XX`, `Anime/<Title>/Season XX`, `Dramas/<Title>/Season XX`) with `.srt` captions paired automatically.
- **History:** Resume any movie, series, anime, or drama episode from the exact timestamp where you paused.
- **Settings:** Download folder picker, default stream quality (`480p`/`720p`/`1080p`), default playback speed, Windows startup toggle, Minimize to System Tray, Desktop Notifications, and GitHub Release updater.

## Content Playback Modes

### 1. Desktop Theater Player (Movies, Series, Anime, Local Files)
- Opens automatically for **Movies**, **non-drama TV Series**, **Anime**, and local video files (`Open File`).
- **Controls:** Play/Pause, seek bar, volume slider & mute, resolution selector, `.srt` Closed Captions (`CC`), audio dub/language switcher, playback speed (`0.5x–2.0x`), video aspect/resizing (`Fit`, `Fill`, `16:9`, `21:9`), Episode Drawer, Next/Prev Episode, Fullscreen (`F` / `F11`), and External Player fallback for unsupported containers.
- **Keyboard Shortcuts:**
  - `Space` / `K`: Play / Pause
  - `Left` / `Right`: Seek `-10s` / `+10s`
  - `Up` / `Down`: Volume Up / Down
  - `M`: Mute / Unmute
  - `C`: Toggle Closed Captions
  - `N` / `P`: Next / Previous Episode
  - `F` / `F11`: Toggle Fullscreen
  - `Esc`: Exit Fullscreen or close active screen

### 2. TikTok-Style Vertical Drama Player (Dramas Only)
- Opens automatically when playing episodic **Dramas** (K-Dramas, C-Dramas, Romance/Melodrama mini-series). Movies, Anime, and action/crime Series stay in the Theater Player.
- **Vertical Episode Navigation:**
  - **Next Episode (Swipe Up):** Drag up on the stage, scroll mouse wheel down, press `Up Arrow` / `Page Down`, or click the down-arrow step button.
  - **Previous Episode (Swipe Down):** Drag down on the stage, scroll mouse wheel up, press `Down Arrow` / `Page Up`, or click the up-arrow step button.
  - Each step moves exactly one episode in ascending Season/Episode order, cleanly disposes the prior player before starting the next, preloads the upcoming episode, and saves per-episode resume positions.
- **Switch Mode:** Use the top-right **Theater Mode** button inside the Drama player at any time if you prefer widescreen playback.
